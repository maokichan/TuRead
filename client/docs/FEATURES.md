# UI 功能组件设计（Feature Components）—— 裁决权威与索引

> **本文职责（feature-docs 机制，2026-11-05）**：承载**用户定案的交互语义**（裁决权威）与
> 功能容器契约；各功能域的**架构锚点、实现细节、验证路径**在 [`features/`](features) 一页一域
> （library / reader / notes / room / settings）。冲突序：CONTRACTS > 本文 > features/ 页 > 其余。
> 视觉语汇一律以 **`STYLE.md`** 为准；六边形/端口见 `ARCHITECTURE.md`；插件 = `client/plugins/PLUGINS.md`（插件侧子树自持）。
> 状态：v0.1.6 落地实施（五 Feature 标准容器 + Tailwind v4 迁移完成）。

---

## 1. 目标与不做什么

**目标**：把 22KB 单体 App.tsx 拆成按交互域划分的 Feature（已交付）；标准化「视图模式 / 域内
状态」；新功能 = 新 Feature 或新展示原语，追加不改动他域；为插件留出 UI 侧边界。

**不做**：服务侧插件运行时（ports 即边界，`ARCHITECTURE.md` §4；渲染层运行时已落地，见 §13）；
UI 状态库（纯 React）。

## 2. 分层与目录

```
src/renderer/src/
├── AppShell.tsx          # 组合各功能组件；唯一的“谁在哪个模式”决策点；跨功能共享态
├── features/             # 功能组件：一个完整交互域，自持该域用例编排
│   ├── {Library,Reader,Room,Notes,Settings}Feature/   # 五域（域参照页见 features/）
│   ├── types.ts / registry.ts   # 标准容器契约 + 注册表
│   ├── chromeSearchBus / libraryNavBus / readerCardBus / roomSession / logStore
│   │                     # 底面全局件与跨功能共享态的模块级总线/单例（归属见 ARCHITECTURE 缝合件表）
│   └── coverCache.ts / format.ts
├── components/           # 展示组件（纯 props，无业务编排）
├── dev/                  # 开发探针（非产品代码；selfCheck + 六专项探针）
├── plugins/runtime.ts    # 渲染层插件运行时（§13；模块级单例，不进 ServiceContainer）
└── styles.css            # 主题语义 token + kookit 契约（Tailwind 入口）
```

**分层纪律**：`features/*` 只依赖 ServiceContainer/用例接口 + `core/domain` 类型 + `components/*`；
不得直接 import kookit / better-sqlite3 / WebSocket 实现。`components/*` 纯展示。

## 3. Feature 划分与边界

| Feature | 职责（编排的用例/端口） | 对外状态 | 关键事件 |
|---|---|---|---|
| **LibraryFeature** | `books.*` + `picker.*` + `covers.*` | `selectedBookId`（聚焦舞台详情与 Room 标定 / Reader 打开共用） | covers 进度/就绪/失败/完成 |
| **ReaderFeature** | `render.*` + `store`（lastLocation 恢复） | 当前书、进度、目录、阅读位置 | `location-changed`、`rendered`；房间侧 `location-updated`（跟随落点） |
| **RoomFeature** | `net.*` + `room.*` + presence/chat | 连接配置/状态、`roomPhase`、成员、聊天 | `connection-changed`、`presence-updated`、`chat-message`、`book-mismatch` |
| **NotesFeature** | `store` 笔记**读模型**；跳转 = `host.openReader(editionId, { revealNoteId })` | **无**（纯查询；**激活时重读**——与阅读器不同屏故不陈旧） | **无** |
| **SettingsFeature** | `store`（appearance/librarySettings/plugins）+ 主题应用 | 主题、全屏、导入选项、插件清单 | 无（启动载入 + 系统主题监听） |

> 房间与阅读是两个独立 Feature：翻页只是 RoomFeature 位置的来源——经用例层
> `emitLocation`/`location-updated` 解耦，不互相 import。服务器连接是房间的一部分。

## 4. 模式与状态标准化

- **视图模式**（Shell 层）：`FeatureId = 'library' | 'reader' | 'room' | 'notes' | 'settings'`；
  `reader` 无侧边栏入口（入口只有书）；`room` 内聊天/位置操作需 `connState === 'connected'`。
- **域内子状态机**：类型联合 + 显式转移（`ConnectionState`/`RoomView`/`JoinFailure`）——UI 不得
  自己拼装状态，状态只随用例结果/端口事件转移；`phase` 与 `error reason` 分开字段。
- **事件→状态唯一接线点**：每 Feature mount 时一次性订阅职责内事件，卸载解绑；杜绝多 Feature
  同听一事件各写各的 setState（拆分前 App.tsx 的主要腐化点）。

## 5. 与插件系统的关系（裁决）

- **渲染权在宿主**（用户定）：插件只落在程序定义的位置——v1 唯一开放位置 = **右欄卡片页的
  面板格**；几何/页签/开合/滚动外壳全部宿主给。
- **v1 只装官方插件**：随应用首发种进运行时文件夹，加载不做沙箱；第三方开放远期（需沙箱与
  审核）。侧边栏 descriptor 口 v1 不开放给插件。
- 插件**不进** `ServiceContainer`（六边形内核不变）；运行时是渲染层外壳的模块（同
  `roomSession`/`logStore` 先例）。**能力边界 / 开发标准 / 生命周期（含卸载）= `client/plugins/PLUGINS.md`**
 ——本节只留裁决，不复读。
- 插件格与聊天**互斥**（`hideWhenInRoom`：进房让位——AI 的「問」用）。

## 6. 已定案记录（宪法——改动须用户明示）

1. **单面板 + 侧边栏导航**：左侧栏 = 功能组件列表（registry 自动发现），主面板 = 宿主容器。
2. **roomPhase.error 携带 JoinFailure**：UI 直接显示 reason。
3. **ReaderFeature 布局模式**：域内自持 + 持久化 setting。
4. **Tailwind v4 同步引入 + 语义 token**：`:root` 暗色 + `[data-theme=…|system]`。
5. **命名**：`features/*/index.tsx`；跨功能共享类型收敛 `features/types.ts`；展示组件收 `components/`。
6. **标准容器**：`FeatureDescriptor{id,label,component}` + `registry.ts` + AppShell 宿主。
7. **状态继承**：功能组件**常驻挂载、非激活 `display:none`**——房间会话/阅读位置不因切换丢失；
   跨功能跳转唯一通道 `FeatureHost`。阅读卡进出场 = **暗场浮现**（`.reader-dip`；原「从被点封面
   长大」随批1.9 退役，git 历史为准）。
8. **侧边栏符号**：繁体汉字单字（書/房/筆，設 钉底；「閱」不入栏——入口只有书）源流明体显示，
   选中态 = 负片块，禁用彩色 emoji。
9. **不引入 `kind` 二级分类**（用户定，纠正一次分类倾向）：侧边栏条目彼此同级；笔记管理只是
   新增一条 `FeatureDescriptor`；容器/宿主/状态继承/跳转一律复用，不为"工具"另起第二套。
10. **阅读标签页模型（批1.10，用户定）**：打开一本书 = 开一个标签（重复打开 = 激活既有标签）；
    **切换 = 重开链路**（B1 代次守卫；B2 真并行留作性能升级）。标签区 = 侧栏 `TagRail`
    （2026-11-03 重设计：窄格首字 + 悬停揭示全题，与 `.feature-nav` 同款几何；**关闭交右键菜单**；
    原顶栏 `ReaderTabStrip` 退役）。Esc / 命令面板「退出閱讀器」= 关当前标签（邻位激活，最后回
    书库）；侧边栏离开 = 卡片收起、标签存活。会话级状态，切库清空。

## 7. 实施落地（AppShell）

- **chrome 底面 + 卡片层宿主**：空间语法见 `STYLE.md` §1.1；五张功能卡经 `FeatureCard` 浮于底面
  （scrim 归阅读卡独占）。无顶栏/无日志栏/无品牌 logo（自绘标题栏退役；Electron 菜单移除双保险）。
- **侧边栏 = 单色符号图标栏**（56px）：`FeatureDescriptor.icon` 繁体单字，label 悬停提示；
  `settings` 钉底（`pinned`）。
- **Tailwind**：`@tailwindcss/vite` v4；`styles.css` 保留主题 token / 全局 base / 滚动条 +
  **kookit 硬编码契约**（`.reader-stage` overflow + iframe 不设 height，KOOKIT.md §5）——两条
  不能用 utility 替代。颜色一律走语义 token，组件内禁写死 hex/rgba。
- **已知例外**：UI 层直用桥已消除（收敛 `IBookPicker`）；仅 `dev/selfCheck.ts`（开发工具）直用。
- **已知无头时序抖动**：书库启动即渲染封面后自检窗口变窄，偶发「渲染可疑」重跑即绿（历史教训见
  KOOKIT.md §8）。

## 8. 书库——交互裁决

> 域参照（锚点/细节/验证）= [`features/library.md`](features/library.md)；契约 `CONTRACTS.md`
> §4.4/§4.5；存储 = `DATA_MODEL.md` §1/§2。

- **两视图**：`列表` / `網格`（**瀑布流已并入网格**——缩略图我方生成统一 2:3）；网格不显示指纹，
  封面 + 标题（**不显示作者**）；状态栏**不显示书目数量**（用户定）。
- **聚焦舞台**（用户定形态全套）：单击 = 选中并弹出全屏焦点态（卡片飞向中央、景深失焦、三维绶带
  流转真实数据）；**聚焦期原卡 = 空缺提示槽**（原位留空 + 淡边框 +「再次點擊打開」，点击直进阅读）；
  **雕塑卡本身可点击**（命中区 = 落定矩形）；**动作交右键**（舞台内不放操作键：打開/詳情/從書庫移除）；
  开场期幕不拦点击（双击语义不变）。旧详情抽屉退役（2026-11-03，git 历史为准）。
- **层级浏览与書箱**：書箱 = 与书籍同地位的一等条目（外观/选中/右键/拖拽/更名全对齐，区别只是
  "打开 = 进入下一层"）；交互对齐文件资源管理器（单击选中/双击进入/F2 更名/右键/拖书入箱 = 移动，
  单亲归属）；**面包屑根固定**（容器固定宽，根锚死子节点右增）。
- **层级后退/前进**（用户定，对齐资源管理器）：历史栈含整条面包屑；两出口 = 底面按钮 + 鼠标侧键。
- **两种建库模式**：映射库（跟踪真实文件夹，不能导入靠扫描对账）/ 自建库（書箱树 + 导入）。
- **全库检索**：检索态跨書箱命中书平面列表，不看当前层；检索态空态优先于「書架為空」。
- **移除语义**：所有"删除" = **取消收录**（只删索引不删源文件，笔记与阅读状态保留）；首次确认
  弹窗 +「下次不再提示」。
- **元数据范围**：本地不采集/不显示 author / publisher（与 server Work 模型一致）；作品身份由
  标准化补齐（入口在房间功能）。

## 9. 阅读器——交互裁决

> 域参照 = [`features/reader.md`](features/reader.md)；视觉细则一律 `STYLE.md` §5.8；
> 可调参数频率表 §5.9。**两条最容易做错的**：全屏的是"桌"不是"正文"；鼠标一动就浮出的栏同样是
> 状态栏。

- **阅读页零控件**：书名/页码/翻页/目录/关闭不常驻、也不做"浮现栏"。`Esc` 分流 = 先退全屏 →
  关当前标签（最后一个回书库）；鼠标路径 = 底面「書」（标签存活）。
- **全局禁选**（用户定，宿主级规则）：文字选择 = 阅读正文专属；`input/textarea` 豁免；正文在
  kookit iframe 独立 document 内不受宿主规则影响。
- **翻页**：键盘 `←/→` `Space` `PgUp/PgDn` + 点击左右 1/4 区域（仅分页）+ 鼠标侧键（仅阅读态）。
- **右欄卡片页**（批1.13–1.21 形态链，用户定）：**两张卡并排在底板上**（批1.18 定稿）+ **纸钉死
  不动**（位移补偿）；**单槽位**；**默认收起**（批1.15"卡片页需要是呼出"）；召唤 = 右上角「卡」
  按钮（主路径）/ `` ` `` 总开关 / `p` / `c` / 命令面板「呼出X」；**筆記迁入卡片页族**；左栏只剩
  目录。
- **目录 = 左缘内嵌件**（批1.20/1.21，用户定）：挂载线**本体退役**（"退役的只是线这个语法"）；
  头部半高处、压印字、显影按距离（远端静息不更暗）；**折叠语法全站退役**（目录常驻，`t` 强隐藏）；
  点击跳转不收起；**空目录占位**（缺失要可见）。跟随当前位置 = 当前条目落列表正中（位置只到章）；
  点高亮 = 看内容不是改内容。
- **聊天只在"经房间进入的那本书"上存在**（用户定）；生命周期归房间；与房间组件共享同一份消息。
- **主题模型**：2 tone × 2 mode，正文页跟随模式（深色 = 该主题深色纸）。
- **不做的**：PDF 像素反相（方案见 KOOKIT.md §7）；剩余阅读参数（字距/字体/对齐等，改法已定 =
  注入，按频率进参数页或设置页）；右侧"模型阅读"容器（预留，原则 = 只占留白不挤压纸）。

## 10. 笔记管理——交互裁决

> 域参照 = [`features/notes.md`](features/notes.md)；契约 = CONTRACTS v0.4.1/v0.4.2；视觉 =
> STYLE §5.10 立案。

- **入口形态 = 左侧功能组件**（用户定；**不再考虑**其他形态）；「工具组件」不是新分类（§6.9）。
- **「閱讀」统计段**（批1.24，用户定"放在左侧边栏的那个，统计全局"）：住侧栏「筆」列表顶部，
  **全局口径**；逐日数据自记录器接入起才有形状（段内注记）；v1 只读不做假交互。
- **作用域**：默认 = 当前库（经 holdings 的查询口径，**不是存储口径**——笔记挂 edition 不挂库，
  跨库共享不分裂）；可切「全部庫」；切库随新库回落。
- **视图两态 = 網格/瀑布流（默认瀑布流），没有列表形态**（用户定）；条目标签 =「書名 · 節 N」，
  章标题 v1 不做；筛选循环 `批註→劃線→全部` 默认批註，**判据 = body 是否为空不是 kind**；
  计数显示筛选后条数（筛选器的必要反馈，与书库"不显示数量"不同）；**空态必须报出被隐藏的
  划线数**（缺失要可见）。
- **跳转**：单击 = 选中、双击 = 跳转（资源管理器语义）；不做详情抽屉。
- **与阅读器的关系**：不同屏（切过去 = 离开阅读器）；阅读器内当前书笔记走卡片页「筆記」页；
  本工具管跨书。**激活时重读即新鲜**——不需要 notes-changed 广播（将来同屏形态出现再补）。
- **用词纪律**：书库「移除」= 只删索引不删源文件；笔记删除是真实删除 → 一律写「**刪除**」，
  两词不得混用；不可逆动作不提供免确认。

## 11. 命令面板（`Ctrl+Shift+P`）

> 全局动作入口。**呼出不动画**（键盘起手的工具，动画就是延迟）。

- **非模态**顶部悬停浮层：输入即筛（子串/大小写不敏感/纯空白 = 全量）、`↑/↓` 循环、`Enter` 执行、
  `Esc`/外点关闭、hover 同步选中；语汇 = 全局工具浮层（圆角，非挂载线家族）。
- **命令 = 纯数据**（label + keyLabel? + run），检索判据 `commandFilter.ts` 纯函数 + 单测；面板
  纯 props；AppShell 条件渲染，每次呼出全新挂载。
- **键位**：意图层 `app.commandPalette`；组合键在输入框聚焦时放行（无修饰键才让位）；开着再按 =
  关闭。
- **命令集 v1**：前往五域（registry 枚举走 `host.navigate`）；退出閱讀器（仅阅读态；多标签时 =
  「關閉當前標籤」）；**呼出右欄卡片页**（清单由 ReaderFeature 经 `readerCardBus` 登记、随页族
  增减）；主題四取向（阅读中同步 `render.applyTheme`）。后续 = 视图切换/阅读器动作，随「配键
  体系」一起做（TODO）。

## 12. 房间入口与副本分发——交互裁决

> 域参照（补书链实现/三道闸门/状态机）= [`features/room.md`](features/room.md)；契约 =
> CONTRACTS v0.4.7/§4.5/§5.1；实现主体 = `RoomFeature.joinAndResolveBook`。

- **进房三路**（统一入口 `enterRoom`）：创建房间（需选中书；**建房即上传副本**，失败不挡进房）/
  大厅行点击（**无书进入**，服务器必收 → 自动补书）/ 手动输房号（有选书 = 带书，未选 = 无书）。
- **补书结果三态**：本地指纹命中直接打开；两端皆无留在房间（日志说明等房主补传）；失败降级为
  无书成员，不回滚加入。
- **跟随模式**（v0.4.9）：开关 = 聊天格「跟隨」；跟**任一**成员（"一起读"，不是监控某人）；
  生命周期 = 本次房间会话，不持久化；**同位不跳**防回声。
