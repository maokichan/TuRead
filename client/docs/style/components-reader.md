## §5.8 阅读器沉浸态

**原则（用户定，对应 koodo 式阅读）**：进入阅读 = 专注文本。**不必要的内容全部退场** ——
无常驻状态栏、无无用功能键、无圆角边框的"嵌入盒子"；界面上只保留需要渲染的文本内容。
两条容易做错的地方先写在最前面：**全屏的是"桌"不是"正文"**；**鼠标一动就浮出来的栏同样是状态栏**。
阅读器浮在**底板**之上的**卡片层**里（风格基线 §1.1 词表）：桌与纸的几何照旧，
**卡片纪律 = 零自带 chrome**（书名进 OS 窗口标题；阅读卡内不出现状态性控件）。

| 规则 | 内容 |
|---|---|
| **纸与桌** | 全屏铺开的是**桌**（桌色 = **底板本色** `--bg`，与底板同色不分层——用户定阅读层平压底板；`--desk-bg` 现役 = 四张功能卡的桌色面与目录遮罩垫底）；正文在**居中的定宽「纸」**里（`--read-width`，px；文字档位 窄 620 / 中 760 / 寬 920，默认 **760**；PDF 专属 840 / 1080 / 1320，见 §5.9 #3）。**内容与背景必须可分，而且靠颜色**（不是阴影/圆角）：纸比桌亮一档（四套主题各一组），纸再有 **1px `--page-edge` 边** |
| **纸的内边距** | `--page-pad-x`（正文到纸边的距离；档位 24/44/72）—— 适配器注入正文 `body{padding-inline}`。这是"出血"唯一的正确加厚位置（§5.9 表 #6 的算术约束） |
| **宿主容器 = 纸** | 滚动宿主仍是 `#page-area`（硬契约，渲染引擎逆向 §5.1/§5.8），但它现在是**纸**（定宽居中、`overflow-y:auto`），外层是**全屏桌**容器。纸宽 = kookit 的排版宽度依据（宿主 `clientWidth`）→ 改纸宽即改"一行多长"、图片缩放与分页宽度，**不需要新端口**。两侧留白 = 未来右侧容器的可增长区（§5.9） |
| **滚轮** | 落在两侧留白上也要能滚：外层桌把 wheel 转发给纸（否则鼠标停在留白上没反应）；纸内部走原生滚动，转发要跳过，否则双倍 |
| **滚动条** | "必要的器"而非装饰，**不得在用户不希望的时候影响注意力**：**2px**；静息只有 `--page-text` **10%**，**指针进入纸内**才升到 26%；**短章节整条隐藏**（判据见下行）。⚠ 只写 `::-webkit-scrollbar`，**不能写标准属性** `scrollbar-width`/`scrollbar-color` —— Chromium 121+ 起写了它们就会让 webkit 规则被**整个忽略**（实测是 `thin` 的 ~11px）。桌容器 `overflow:hidden`，滚动条不会跑到屏幕边缘 |
| **短章节的判据** | kookit 给文字类 iframe 的 `height` 硬留 **+300px 余量**（`handleIframeHeight`），所以"短章节也总有得滚"不是真溢出。溢出 ≤ 余量时适配器设内联 `scrollbar-width: none`（**完全不占位**：标准属性优先正好当开关用）；真溢出才让 2px 规则生效 |
| **阅读页零控件** | 书名、页码、上一页/下一页/目录/关闭**都不常驻、也不做"浮现栏"**。进度与位置不占操作面 |
| **退出** | `Esc`（键盘，分流：先退全屏 → **关当前标签**——邻位标签激活则留在阅读态，最后一个回书库）；鼠标路径 = 底面图标栏「書」（阅读态常亮宣示来处；点击 = 收起阅读卡回书库，**标签存活**、书目与阅读位置存活）。**不为退出在阅读卡上加按钮**（卡片纪律） |
| **沉浸全屏** | `F11`（意图层 `reader.enterFullscreen`）= **进入**全屏（**幂等，不是切换**——阅读器内按 F11 是切换全屏状态）；或设置开关（「進入閱讀器時進入全屏」，默认关）。进入后 = OS 级全屏（底面顶条带的全局件保持可见）。**退出全屏 = `Esc`**（分流：先退全屏 → 再退阅读器）。**离开阅读器时若正处于全屏 → 退出全屏并「设为最大化」**——沉浸态结束后窗口留在"大"的状态。⚠ 实现在主进程（`win:set-maximized`，**幂等**；全屏未退干净时挂到 `leave-full-screen` 再最大化）；`Esc` 在阅读器内退全屏（不离开阅读器）**不**触发最大化 |
| **翻页** | 键盘 `←/→` `Space(分页模式)` `PgUp/PgDn`；鼠标点击左右区域（仅分页模式）；scroll 模式滚轮。**点击带 = 左右各 1/4**（[`client/src/renderer/src/features/ReaderFeature/index.tsx`](../../src/renderer/src/features/ReaderFeature/index.tsx)；口径裁不一（§5.8 旧写 1/3）随待办「布局语义一等化」一并定）。**目录开合 = `t`**，**右欄卡片页总开关 = `` ` ``**，**阅读参数面 = `p`**，**聊天面 = `c`**（只在经房间进入的书上有这一面，无则按键不做事）——均为键盘、无界面痕迹 |
| **图标栏恒可见** | 卡片模型下侧边栏是**恒定框架**：阅读态不隐藏、不覆盖，「書」常亮宣示"你在哪"（下层书库存活）；图标栏直接坐在 chrome 底面上（无底色、无分隔线，风格基线 §1.1） |
| **右欄卡片页（形态 = 独立卡片页，用户定"卡片页和阅读器界面平级"）** | 右段 = **阅读卡的兄弟卡**（`.rail-card`）——不是阅读卡内的浮层；AppShell 卡片区的 scrim 容器是 flex 行，阅读卡与槽位并排、**中间一道沟露出底板**（`--rail-gap`），双卡同顶同底、**地位平等**，各自一张卡面（**底板本色** + `--radius-panel` + 1px 边，**无阴影**——卡面与底板同色才是平压，桌色深一档会在浅色下读作影；右欄卡同档）。自右**滑入显影**（`--dur-panel` 强 ease-out；收回更快 `--dur-hover`，收完卸载）。**纸钉死不动**（用户准绳"没有直接影响到显示内容区的时候就不要改变显示内容区的宽度"）：`--page-w` **锚定视口**（固定 token，纸宽与开合无关）；阅读卡收窄导致的 re-center 由 `.reader-stage` 的**位移补偿**精确抵消——**单驱动**：开合只过渡注册属性 `--slot-w` 这一个值（`@property` 可插值，过渡挂 `.reader-scrim`），槽位宽度与纸位移每帧读同一个数 → 纸静止由构造保证、零重排。**单槽位**（用户定）：一次一张卡，页签切内容不重播进出场；页族 = **參數 / 筆記 / 聊天（仅房间）/ 插件格**，页签序同此（页签 = `.rail-tabs` 等分、对卡片中心对称、**钉在卡片底缘**（顶缘让给「卡」按钮保双态同位），页签行不随内容滚动）。**召唤 = 右上角「卡」按钮（用户定，鼠标主路径）**：压印字双位点（静息墨色 = **专用档 `--card-corner-ink`**，浅 20% / 深 26% 起步——比目录压印字浓一档：目录有邻近显影撑腰，卡按钮只有 hover，可发现性校准见「不建引导系统」裁定）——阅读界面右上角（卡收起时）/ 卡片页右上角（卡展开时，**双态同位**——同一操作不改变位置；页签行已沉到卡片底缘，点击缩回）；键盘 = `` ` ``（总开关，开→上次的页、首次 = 參數面）/ `p` / `c` / **命令面板「呼出X」**（`[client/src/renderer/src/features/readerCardBus.ts](../../src/renderer/src/features/readerCardBus.ts)` 登记，随页族增减）——均作加速器。**默认收起（用户定"卡片页需要是呼出"）**：默认视野 = 纯正文 + 目录；重开书保持收起。`Esc` **先收卡片**、再退阅读器。**收卡只归右上角「卡」按钮**（各内容页尾部的「折疊」按钮已清除——折叠这个语法已退役，不再引入；键盘 Esc/`` ` `` 不变）。**纸照旧让位**（`--page-w` 算式不变，住右侧常驻让位区里）。⚠ **筆記迁入卡片页族**（用户定"笔记，AI，插件，都可以有同样的归属"）：左栏只剩目录（常驻内嵌），`focusNote`（点正文高亮看内容）= 切卡片到筆記页并定位正中 |
| **阅读器聊天室（卡片页族·仅房间）** | **沒有通過房間進入一本書就不會有這一項**。① 只在经房间进入的那本书上出现（判据 `roomId && roomEditionId === readerBookId`；非房间的卡片页族**不出现「聊天」页签** —— 机检 `noRoomTabsOk`）；② 语汇沿用列表行家族（`.toc-list` 行语汇 + `--toc-veil` 按距离遮罩；容器几何归 `.rail-card` 外壳）；③ 消息行 = 抬头（昵称 + `HH:MM`，12.5px `--muted`）+ 正文（15px `--text`，`pre-wrap` 折行）；④ **输入区属 §5.2 例外①**（发丝描边 + 直角；Enter 送出 / Shift+Enter 换行 / 自增长到五行封顶转滚动，与 `.note-composer` 同一操作口径）；⑤ 新消息到达**自动滚到底**；⑥ 开合 = 「卡」按钮 / `` ` `` / 页签 / `c` / 命令面板。⚠ **生命周期归属于房间**：离开房间 → 页签与消息一并消失（消息历史仍在服务器，随房间级联清理）。⚠ 机检 `chatDrawerOk`（三格页签 + 页签行对**卡片中心**对称 + 与参数卡**同宽同高上限** + 有消息行 + 输入框发丝描边） |
| **右键挂载菜单（动作区可见度）** | 形态是"线 + 自线下方生长"，但**动作区不透明**：纯色底 `--panel-2` + 1px `--border` 描边，项文字 `--text`（hover → `--accent` + `--accent-soft` 底）。理由：它挂在**正文纸上**，靠"内容与背景同色"读不出来 —— 见 shell 页 §5.2 例外⑥ |
| **批注输入栏** | 底部中心对齐、纯色带边框容器、**零提示词**、作为焦点存在；填充阅读纸的部分、两侧只留相对约 5% 的缝隙；高度默认两行、内容多了自动撑起。落地 = 屏幕**底部居中**（`fixed bottom-6 left-1/2 -translate-x-1/2`，**不跟随右键坐标**）、纯色底 `--panel-2` + 1px `--border`、**零文字**（无标题、无 placeholder、无按钮 —— 焦点态由 `:focus-within` 给 `--accent` 边）、**宽 = 纸宽（`--page-w`）× 0.9**、**自增长：空态两行 → 内容多了撑到五行封顶 → 再多则框内滚动**（`field-sizing: content` + `min/max-height`，Chromium 123+；Electron 33 = 130 已实测生效，无需 JS 量高）。操作逻辑：挂载即聚焦、`Enter` 提交、`Shift+Enter` 换行、`Esc` 取消。**生命周期 = 输入框绑在它的对象上**：对象是**选区**（右键「加批註」/键盘 intent）或**笔记**（「編輯批註」/点高亮/笔记页行内「編輯」）—— 选区消失关前者，**笔记从库里消失（含在卡片页筆記页删掉那一条）关后者**，另加关书/换书/右键别处/Enter/Esc。⚠ **移除既有笔记**因此只剩**右键菜单**一条路径。⚠ 机检：`composerOk`（判据清单见 [acceptance](acceptance.md) 页 §8.0）。⚠ **单击正文高亮 = 看内容，不是改内容**：落地 = 右欄卡片切到「筆記」并把该条**定位到正中**（只读）；要改走**右键菜单**或**笔记页行内的「編輯」** |
| **笔记页的笔记行（右欄卡片）** | ① **行内「編輯」**（静息隐形、hover 显形，与「移除」同款）：点它打开底部输入栏并带出该条正文，**焦点自动落在输入区**（[`client/src/renderer/src/components/NoteComposer.tsx`](../../src/renderer/src/components/NoteComposer.tsx) 挂载即聚焦）。② **「註」符号**：`body` 非空的行在元行显示汉字单字「註」——视觉上区分**批注**与高亮；判据是 **`body`**，不看 `kind`（与全站一致）。正文侧的区分另有 kookit 自画的 `.kookit-note-icon`（探针实证）。⚠ 机检：note 探针「带批注正文的笔记行显示「註」符号」「笔记行有「編輯」入口」「焦点自动落在输入区」 |
| **插件面板格** | **右欄卡片页**开放给**官方插件**注册面板格（契约 = [`client/plugins/PLUGINS.md`](../../plugins/PLUGINS.md)，功能 = 功能总纲 §13）：**页签机制不变**（`.rail-tabs` 等分、对卡片中心对称）；**外壳归宿主**（`.rail-card` 卡面 + `--rail-panel-w` / `--rail-panel-h` 同一 token / 顶部页签），插件只拿内容区元素；插件内容**纯文字 + token**，不得自创视觉语汇（P1/P3 红线同样约束插件）。⚠ 样张**不加载插件** → [acceptance](acceptance.md) 页 §8.0 的 `noRoomTabsOk` / `chatDrawerOk` 语义不变（那两条判的是**聊天**页签泄漏，不是插件格）。⚠ **卡片页 = 插件贡献点的未来落位**（用户定"任何一个插件都可以在阅读界面是一个卡片"，形态随批次裁，待办在档） |
| **显影淡入 / 卡片页弹出** | 两套进出场，同一状态机（`useHangingPanel`：收完才卸载，收回期间 `pointer-events:none`）：**左内嵌目录** = **透明度显影**（目录是低注意力内嵌件，不做大动作），进 220ms 强 ease-out、收回 160ms（出比进快）；**右卡片页** = **从右滑入显影**（自右 24px + 透明 → 归位，`--dur-panel`；收回 `--dur-hover` 更快）——「独立的卡片页」的空间故事在时间上成立（用户定）。实现 = `.rail-hang`（显影）与 `.rail-card`（滑入）各一套 CSS + `@starting-style`（Chromium 123+ ✓；不支持时无动画直接出现）。右键菜单同款自线向下揭开（`--dur-hover` 160ms；收回 = 瞬时卸载，高频短命浮层不表演）；**子菜单自左缘向右揭开**（它是"从父项里长出来的"）。reduced-motion = 去掉位移与揭幕（卡片页保留显影） |
| **灯的法则** | **光标即光源**：静息元素随光标距离**连续呼吸**，不再二值跳变——接近度因子由 [`client/src/renderer/src/components/veil.ts`](../../src/renderer/src/components/veil.ts) 的 `paintGlow` 写（欧氏距离，衰减半径 110px），换算归 `styles.css`（CSS 仍是权威，`hover/focus-visible` = 满亮下限）。**内嵌目录的显影因子（`--row-near`）同由 paintGlow 写**——同一法则，列表上是"字色显影"。滚动条暂仍是二值（随 Veil 优化批一并评估）；鼠标进入书 iframe 时宿主收不到 mousemove → 静息（阅读时安静是**预期**） |

**目录 = 左缘内嵌件（用户定形）与右欄卡片页**

目录**在阅读卡内部**，形态 = **内嵌件**——阅读卡内部左缘、挂靠阅读器边缘、
**头部处于阅读器半高处**（top: 50%，用户定"不要顶住头"）、条目向下排列到底部留缝。
**无折叠：目录常驻**，`t` = 强隐藏（唯一开关）；卡片页鼠标召唤 = 右上角「卡」按钮。
快捷键：参数 `p`、目录 `t`、聊天 `c`；命令面板给全部卡片页的「呼出X」。

| 项 | 规则 |
|---|---|
| **内嵌目录** | 目录**内嵌**在阅读卡内部左缘（left: 0、宽 = `--rail-panel-w`、top: 50% 至底缘留 16px），容器全透明、无挂载点；**常驻**，`t` = 强隐藏（唯一开关，不持久化，换书回到展示态）。条目**基础左缩进 24px**（用户定"条目太靠边缘"）+ 层级深度缩进 |
| **贴卡缘；右卡 = 兄弟卡** | **内嵌目录**贴阅读卡左缘（left = 0、top: 50%）、宽度 = `--rail-panel-w`；**右欄卡片页**是阅读卡的**兄弟卡**（同置底板之上，中间一道沟 = `--rail-gap`）、与目录**同宽**（同一 token）、全高（同阅读卡顶底缘）。⚠ **宽度不许写成纸宽的函数**（改纸宽不得带着两件一起变）。⚠ 机检：[`client/scripts/style-gallery/smoke.cjs`](../../scripts/style-gallery/smoke.cjs) 的 `cardOk` 与 `widthIndependentOk`（[acceptance](acceptance.md) 页 §8.0） |
| **纸给挂件让位** | **让位的是纸，不是线**（挂件遮住纸的内容不可接受）：`--page-w = min(用户档位, 100vw − 侧边栏 − 2×inset − 2×(挂件 + 缝))`，全固定 token、**锚定视口**；`.reader-stage` 与输入栏都读它（单一定义处，[tokens](tokens.md) 页 §3.4）。阅读卡收窄由 `.reader-stage` 位移补偿（`--slot-w` × ½）抵消——**呼出/收起，纸的位置与宽度都纹丝不动**（kookit 零重排；补偿与槽位宽同读单驱动值）。挂件/卡宽仍是**固定 token**（不随纸变）。代价：窗口不够宽时选「寬」会被夹到可用宽（正文变窄）。⚠ 机检：`paperClearOk`（真机在 note 探针、样张在 `smoke.cjs`：纸与两件**横向不相交**）+ `paperStillOk`（**过渡中**的动态判据） |
| **卡片页顶部的页签行** | 页族页签**等分卡片宽度、文字各自居中**（等宽 flex，不加 gap）。⚠ 参照是**卡片自己的中心**（不是窗口中心、不是演示框中心）。⚠ 机检：`tabsSymOk`（页签行中心 = 卡片中心 ±1px；标签带计数后缀 → 前缀匹配） |
| **跟随当前位置** | **用户读到哪里，哪个条目就落在列表正中**（目录与笔记同口径）。判据是**纯函数**（[`client/src/renderer/src/components/readerFollow.ts`](../../src/renderer/src/components/readerFollow.ts) + 单测）：目录 = **章号 ≤ 当前位置的最后一条**；笔记 = **当前章的第一条**（本章无笔记则退化为之前最后一条）。打开/换书 = 瞬时落位，跨章跟随 = 平滑滚动。⚠ **粒度诚实**：位置只到**章**（kookit 不给章内进度）→ 章内精确到某一条已登记入唯一待办清单。⚠ 机检：`followedOk`（**先要求列表真的能滚**，再量偏差 ±8px） |
| **半高起排** | 条目自**阅读器半高处**开始、逐条向下排列（一条条向下 ≠ 卡片/抽屉盒子），左端贴阅读卡左缘（用户定"目录头部处于阅读器半高处，不要顶住头"） |
| **容器全透明** | 条目容器**完全透明**（没有底色）。层级靠排版与留白，不靠底色（P2/P3） |
| **压印字 + 字色显影** | 目录行两层：**压印基底** = 静息淡字（`--toc-press-ink`，拟物 letterpress）+ 两道边缘阴影（`--toc-press-hi/-lo`，亮缘在下接反光、暗缘在上沉凹刻——用户定"透明字符边缘阴影"，不只是 hover 高亮一种语义）；**显影层** = 同文字全强度副本，透明度 = 接近度因子（`--row-near`，`paintGlow` 写，欧氏距离 110px），过渡 200ms。⚠ **不变量：远端条目保持静息，靠近只"显影"到全强度，绝不比静息更暗**；hover/聚焦 = 满强度。（参数面/聊天行的遮罩 `--toc-veil-rest` 语汇不变，仅目录是压印字） |
| **静息更淡** | 参数面/聊天行静息遮罩 `--toc-veil-rest: 0.74`（按距离遮罩语汇，仍在用）；内嵌目录与「卡」按钮的静息 = 压印字淡字档 `--toc-press-ink` |
| **默认展示** | 有目录的书**默认就是展开的、常驻**；**点击条目跳转不收起**；`t` = 强隐藏 |
| **长题 = 悬停滚动（用户定）** | 条目静息照旧省略（单行 ellipsis）；**hover 该行时换装成 `Marquee` 无缝滚动**读完全题（侧栏标签胶囊同款语汇，`pauseOnHover` 必关——该层只在 hover 时存在），字色全强度、桌色垫底盖住下层；键盘聚焦 = 静态全强度（不滚动） |
| **不遮正文的理想态** | 浮层不改变纸的位置与宽度（`position:absolute`，不参与布局）；纸够宽时目录落在左侧留白内 |

> 例外登记（shell 页 §5.2 例外清单）之外不加新浮层。
> **阅读页没有任何常驻栏** —— 进度线/顶栏这类"浮现栏"不算例外，不得再加。
> 无头自检硬契约：正文宿主保留 `id="page-area"`；侧边栏「阅读」按钮保留（`aria-label="阅读"`）供真实用户路径断言。

## §5.9 阅读页可调参数清单 + 预留（**登记，逐步实现；不要 one-shot**）

**为什么要这张表**：阅读器的"可改"和"常改"是两件事 ——
**常改的参数必须随手可及，不常改的留在设置里**；而"随手可及"不得退化成常驻控件面（§5.8：阅读页零控件）。
下表是判断依据，动手前先回这里看频率与改法。

**A. 参数清单（按"改动频率"排）**

| # | 参数 | 影响面 | 现状 | 改法（技术路径） | 频率 |
