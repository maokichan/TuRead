## 1. 强交互研读（模型驱动的阅读假设）

研读型阅读从来强交互（查证、理脉、对照多源）；这不是新需求，新的是**成本曲线**：模型让工具走向文本
（带着阅读位置上下文就地干活），并把提取工作接过去（人从抄写员变成策展人）。摩擦降一个量级，
交互频率变一个量级——偶发查证变成连续的对话式研读。判据：

- 工具是**客人**：零延迟召唤、零残留退场；产出落进**用户拥有的结构**（笔记库、用户画的图），不是聊天日志。
- 模型驱动 ≠ 聊天优先：**预计算的上下文**（如"本章提到的人名，已抽好，悬停即现"）优于对话入口；聊天是未预料问题的兜底。
- 一切产出必须能**锚回原文**——定位系统的锚点级溯源是竞品没有的护城河，强交互做得越深它越深。

## 2. 卡片层次化（界面的空间语法）

**chrome 底面 + 卡片层**是全部界面（不止阅读）的空间语法（用户定）：
窗口背景是一块**连续的 chrome 底面**——导航图标与窗控只是住在它上面的内容，
不存在"栏"的视觉边界；区域划分靠不可见的留白（inset / gutter）声明，不靠分隔线或底色差。
书库、阅读、笔记、房间、设置五张卡都是浮在底面上的 **surface**，共用一套卡面语法
（桌色面 + 圆角 + 1px 边 + 面板阴影）；阅读卡的恒态背景 = **底板本色**（批1.15 起：
原"独占 scrim 压暗书库"的视觉退役——书库存活但不可见），scrim 只活在进出场"暗场浮现"的一瞬（§3）。工具的归属随模型定：

- **搜索是全局件（批1.11，用户改定——原"搜索住进卡片"退役）**：住底面顶条带**左簇**（批1.12 定位：紧跟后退/前进；右缘让位窗控），
  **全局生命周期**：恒在，职能按激活域分流——书库搜书 / 笔记搜笔记已接线（检索词归各功能自持，
  经 `chromeSearchBus` 注入），阅读器/房间只有域占位（后端接线见 TODO）；无绑定的域输入框禁用。
- **窗控（最小化/最大化/关闭）是真正的全局件**：直接坐在背景右上，背景整面可拖拽。
- **后退/前进是全局件（批1.11 起恒在）**：悬浮背景左上，**不随状态消失**——职能按域分流：
  书库域 = 层级历史；其余域尚无历史机构（阅读跳转历史 / 房间域返回见 TODO）→ 恒禁用。
- **阅读标签条是全局件（批1.10，用户定；2026-11-03 用户定迁形）**：标签住**左侧栏**（TagRail：线上功能图标、线下开着的书），顶栏 = `‹ ›｜搜索｜窗控`。**打开一本书 = 开一个标签**，
  一本书一个标签（重复打开 = 激活既有标签）；标签 = 阅读会话的**在场**——切去书库/设置后标签仍在，
  点标签唤回阅读卡（书不重开、位置不丢）；关掉当前标签激活邻位，**关到最后一个标签 = 回书库**
  （书库扮演"新标签页"）。Esc / 命令面板「退出閱讀器」= 关当前标签，不再直接等价"离开阅读"。
- 阅读卡"零自带 chrome"升级为全卡片纪律：卡片自带自己的语境工具，背景不随状态变含义；
  书名仍声明进 OS 窗口标题（阅读器作用域的搜索占位见上——禁用态恒在，不假装可用）。

阅读界面 = **浮在底板之上的卡片层**；不是弹窗，也不是全屏沉浸窗。层级由空间本身声明：
下层（书库）存活但不可见（批1.15）、侧边栏常亮「書」——"阅读器和书库层的关系"由布局回答，不靠返回按钮解释。

- 进出动效隐喻：**暗场浮现**——现场先沉入暗场再松开（scrim 只往深里走，深色主题是"更暗一瞬"，
  不做亮块闪光），阅读卡**原比例**自下浮起，退场反向、更快。大比例 scale 长大（原文"从被点封面的
  位置长大"）让文字参与形变、观感生硬，已退役；"吞没—浮出—复原"的节奏参照视图切换动画的思路，
  但颜色只取深不取亮。
- 沉浸态哲学演进：从"一个全屏状态"变为**卡片自身的纪律**（零控件约束移交给卡片）；
  STYLE §5.8 按卡片纪律重立；F11 维持 OS 级全屏语义（卡片纪律不依赖全屏）。
- 该模型同时是 §1 的基底：阅读卡是锚面，地图/白板/对照的另一本书都是同一套空间语法里的层。

## 3. 端形态（桌面 = 书房）

竖屏设备的优势在**线性消费**（身位：躺着/通勤读；栏宽：竖屏宽度天然落在理想行长）；
桌面的优势在**画布**（地图、关系图、多书对照、键盘、精确指针、多面板）。两种阅读的物理规律不同：

- **TuRead 不与手机抢床边那本书，赌的是书桌前那两小时。** 桌面端 = 研读仪器（本方向的主场）；
  线性消遣让给竖屏设备，不追。
- 远期跨端形态 = **竖屏轻读端 + 桌面研读端共一份数据**，各干各的活；不是把桌面端缩小。
- **挂载线的定位（批1.13 起进入退役程序）**：它曾是研读模式的核心机构（正文零控件 + 工具恒定可达），
  不是横屏遗留。**批1.13（用户定）**：右段先行换形 = **独立的卡片页**（单槽位，页族 =
  參數/筆記/聊天/插件格，自右滑入、命令面板可呼出）——"工具恒定可达"由**召唤制**接棒
  （「卡」按钮 / `` ` `` 总开关 / `p` / `c` / 命令面板——批1.21 起「卡」按钮替代线右段）。**批1.14 平级化 + 批1.15 呼出制（用户定）**：
  卡片页与阅读卡**平级**（兄弟卡，中间一道沟露出底板）、**默认不在场**（"卡片页需要是呼出"）；
  阅读态背景 = **底板本色**（原"阅读卡叠书库、scrim 压暗"的视觉退役——书库存活但不可见）。
  **目录已随批1.20/1.21 落定为阅读卡左缘内嵌件**（"目录仍然有保留在阅读器内的必要"兑现；垂挂退役）。
  线本体已随批1.20 退役；
  **卡片页 = 插件贡献点的未来落位**（用户："任何一个插件都可以在阅读界面是一个卡片"）；
  竖屏跨端时线可转世（底边线、面板自下升起），届时另议。
