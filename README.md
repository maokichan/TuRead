# TuRead

**多人房间共读阅读器**：几个人进同一个房间，共读同一本书，实时同步彼此的阅读位置与聊天。
渲染/解析复用[kookit](https://github.com/koodo-reader/kookit)（AGPL-3.0）；同步服务器用 Go。

> **现在的状态**：**本地阅读侧已经能用**（导入 / 书架与书库 / 多格式渲染 / 沉浸式阅读器 /
> 笔记与划线 / 跨书笔记管理 / 主题与阅读参数），**房间功能已上线且闭环**：建房即传副本、
> 没有书的成员进房自动下载入库、聊天、**跟随模式**（聊天格「跟隨」开关，成员翻页你跟到同一位置）。
> 阅读器右欄卡片页的「聊天」只在**经房间进入的那本书**上出现。
> **插件系统与 AI 共读已上线**：右欄卡片页多了「時鐘」與「問」（AI 共读助手，自带 key，
> 引用原文可点跳回）。当前版本 **client v0.2.8 / server v0.2.2**。

## 一、给使用者

### 它是什么

一个**不搬动你的书**的阅读器：导入 = 在库里建一条索引（**不拷贝文件**），移除 = 只删索引
（**源文件不动**）。书库只是"组织方式"，同一本书可以出现在多个书库里；笔记与阅读进度跟着
**书的内容**走，不跟着库走。

### 现在能做什么

| 能力 | 说明 |
|---|---|
| **导入与书库** | 导入单个文件或整个文件夹（含子目录）；**映射库**跟踪真实文件夹（改动靠"掃描"对账）、**自建書箱**由你手工组织；书籍与書箱支持拖拽、右键「移動到」、层级后退/前进 |
| **聚焦舞台** | 单击书卡 = 全屏焦点态：卡片携旋转飞向视口中央、页面景深失焦、五条三维绶带绕卡流转**真实阅读数据**（时长 / 进度 / 来源 / 收录）；原位空缺留浅提示「再次點擊打開」直进阅读；动作在右键菜单 |
| **渲染格式** | EPUB / MOBI / AZW3 / PDF / TXT / MD / FB2 / DOCX / HTML …（整体交给 kookit；TXT 自动检测编码） |
| **沉浸式阅读** | 阅读 = **浮在书库之上的卡片**（阅读页零控件，退出 `Esc` 或点图标栏「書」）；全屏的是"桌"，正文是居中的"纸"；阅读态 = 底板本色之上的**两张卡**：阅读卡（正文"纸"居中，零控件）+ **右欄卡片页**（呼出制——右上角「卡」按钮 / 反引号总开关 / `p` / `c` / 命令面板；页族 = 參數/筆記/聊天/插件格，呼出/收起纸纹丝不动）；**目录 = 阅读卡左缘的内嵌件**（半高起排、压印字、靠近逐字显影，`t` 强隐藏；长题悬停滚动） |
| **阅读参数** | 字号 / 行距 / 段距 / 纸宽 / 纸内边距 / 佈局（滾動·單頁·雙頁）；改动即时生效（PDF 改纸宽会原地重开以重新填充） |
| **笔记与划线** | 正文里选中 → 右键菜单：四色**標記** + **加批註**；底部居中输入栏写字（`Enter` 保存、`Shift+Enter` 换行、`Esc` 取消，两行起步、最多五行）；右欄卡片页「筆記」列出本书笔记（带批注的标「註」），可跳转 / 編輯 / 移除（点正文高亮 = 查看该条） |
| **跨书笔记管理** | 侧栏「筆」：網格 / 瀑布流两态、按批注或划线筛、检索、双击跳回原书原处；列表顶部**「閱讀」统计段**（26 周贡献图 + 今日/本週 + Top5，全局口径） |
| **主题** | 四套取向：纯色·深 / 纯色·亮 / 羊皮纸·亮 / 羊皮纸·暗（跟随系统的只是"模式"） |
| **窗口** | 无边框窗口 + **chrome 底面**（顶条带内嵌全局搜索栏：按功能域分流——书库搜书（**全库检索**）/ 笔记搜笔记，其余域禁用占位）；后退/前进恒在（书库域 = 层级历史） |
| **房间与共读** | 侧栏「房」：填服务器地址与昵称 → **連接**（领成员凭证）→ 大厅刷新/进房/建房；进房后**自动打开那本书**，阅读器右欄卡片页出现「**聊天**」页（`c` 键切换）；成员与位置走 `room.presence` 全量快照、聊天走 `room.message` 广播（含自己的回执）；**离开房间 = 断开连接**，聊天历史留在服务器并随房间级联清理 |
| **插件與 AI 共读** | 右欄卡片页可挂官方插件（設置 → 插件 可启停）：**時鐘**（純文字走時）、**問**（AI 共读助手——带着当前位置与全书目录对话，引用原文『…』可点跳回原文；OpenAI 兼容接口，密钥系统级加密保存） |
| **房间的限制（还在收尾）** | 多人同时在线的手感未做真机复核；已知模型限制：同 IP 多开共享成员凭证会互相顶线（NAT，远期 nonce 区分）、聊天消息暂无长度/频率约束——均登记[`TODO.md`](TODO.md)|

**快捷键**（阅读器内）：`←/→`、`PgUp/PgDn`、`Space`（分页模式）、`` ` `` **右欄卡片页总开关**、`t` 目录、`p` 參數面、
`c` 聊天面（仅房间内的那本书）、`F11` **进入**全屏（退出全屏用 `Esc`）、鼠标侧键翻页、
分页模式下点击左右区域翻页。

### 怎么拿到 / 怎么跑

- **免安装便携版**（Windows x64）：`client/release/TuRead-<版本>-win-x64-portable.exe`，双击即用。
  ⚠ 这个目录**不进仓库**，需要本机打包（见下）；仓库里最新已打包的是 **v0.2.8**。
- **从源码跑**（需要 Node 20+）：

```bash
cd client
npm install
npm run dev            # 开发模式（Electron + 热更新）
npm run dist           # 打包免安装便携版 → client/release/（需代理）
```

- 数据都在本地：一个 SQLite 库 + 一个极小的 JSON 引导文件；封面是跟内容走的缩略图。
  换机器时把数据目录整体搬走即可。

## 二、给开发者

### 仓库结构

| 目录 | 是什么 |
|---|---|
| [`client/`](client) | Electron + React 桌面客户端（六边形架构：`core/{domain,ports,usecases,adapters}` + `renderer/`） |
| [`server/`](server) | Go 同步服务器（房间 / 书籍标定 / 副本分发 / 位置广播 / 聊天），独立 module |
| [`kookit/`](kookit) | 渲染引擎（Koodo Reader 的核心，**git submodule**，AGPL-3.0） |
| [`client/plugins/`](client/plugins) | 插件开发工作区（产品获取 = GitHub Release zip 手动安装；契约见 [`client/plugins/PLUGINS.md`](client/plugins/PLUGINS.md)） |
| [`docs/`](docs) | 项目级文档：状态与交接、共同架构、竞品landscape |
| [`client/docs/`](client/docs) | 客户端文档：契约 / 数据模型 / 架构 / 风格基线 / 功能组件 / 渲染接口 / kookit 逆向 |

### 常用命令（[`client/`](client)）

```bash
npm run dev            # 跑起来（Electron + HMR）
npm run dist           # 打包便携版（Windows x64；需代理）—— 口径见 client/docs/BUILD.md（打包由仓库负责人决定何时做）
```

服务端：

```bash
cd server
cp turead.toml.example turead.toml
go test ./...
go build -o turead-server ./cmd/server
```
