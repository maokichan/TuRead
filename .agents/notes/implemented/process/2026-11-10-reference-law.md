# 决策：引用即链接与文档结构治理（STATUS 废除 / 向上引用无合法形态 / 日期退役）

Status: implemented

## Problem

文档体系三处系统性腐化，机制层看不见：① 状态文档层积成地质剖面且与事实矛盾（同一张表两行说反话、已上线事项挂未来时、机器事实进开源仓库），换届 agent 会被读入当真；② 全仓引用八成不走链接形态——反引号壳、裸路径、裸文档名混用，而跟踪守卫对非链接形态存在三层盲区（裸词不识别、裸名死后静默、hook 不读失效报告），删除一份文档后 48 处引用悬空而守卫报「无漂移」；③ 下层文档大量指向上层（子页指父权威、域文档指待办清单），读者被倒灌入口层内容，渐进式披露失效。

## Decision

用户终裁，三件一体：

- **STATUS 废除**：不存在独立状态文档。版本发现 = git tag 与提交消息；决策结论住各域文档正文；论证与放弃项住本日志；交接实态住根入口的指针（几行）；下一步唯一清单 = 待办清单。
- **引用即链接**：所有指向仓库实物的引用（md 链接之外的一切形态——反引号壳、裸路径、裸文档名、裸词干）必须写成 `[]()` 链接；解析不到仓库实物的不算引用（散文词对、模板串合法）；链接目标不存在 = 死链，拦截；docIndex 升级为「引用必须链接 / 死链 / 死引用」三查全拦截，文件名全仓唯一索引补齐裸名解析。
- **向上引用无合法形态**：解析目标在引用文档祖先目录（含仓库根）的引用——链接、反引号提及、裸词干，任何形态都违规。唯一处置 = 删除或改写为不含路径 token 的中文表述（如「唯一待办清单」「契约总纲」「风格基线」）。竖直导航由入口链承担：读者从顶层进来，下层不回指。纯目录引用形态自由；平级 / 子一级 / 跨支引用合法且必须链接。
- **散文日期退役**：入库文档正文禁 `yyyy-mm-dd`——日期归 git 历史与笔记文件名；本日志（事件日志）正文放行，路径即元数据。docGuard 增日期门禁。

执行面：全仓引用普查（57 文档），非法形态真引用 543 处转链接、散文日期 55 处退役、向上引用 106 处消除；docGuard 增日期门禁；docIndex 重写为上列三查。

## Alternatives considered

- **保留 STATUS 做最小洗**：输在——职能重复无主（版本历史 = git 的影子、决策索引 = 域文档与日志的影子），洗完还会再层积；层积的根因是「无机制负责发现腐烂」，留着就留着病。
- **决策按域重排进 STATUS**：输在——入口被迫全域阅读，渐进披露违反照旧；且域决策的结论本就该住域文档。
- **向上引用以路径提及形态合法**（本批执行中曾一度如此实现，用户驳回）：输在——渐进式披露的下层不该回指上层，「提及不算导航」是机器视角的诡辩；对读者而言提及与链接同为回指，合法形态不存在，唯有消除。
- **维持声明制跟踪**（某批之前的 docIndex v1）：输在——覆盖率恒低（39 文档仅 10 个声明），引用本身就是跟踪意图。

## Consequences

换来的：引用单形态（链接）可机检，死链/向上/裸写三类在提交时全部拦截；状态无处层积（无状态文档可烂）；日期不入正文。付出的：链接目标必须存在（写文档时要确认目标实物在库）；下层文档不再自带「上哪找权威」的指针，发现链完全依赖入口读序与域文档自身（入口读序没列到的权威，下层读者无从发现——入口读序成为关键维护面）；本日志的对表义务加重（机制变更须同步本篇）。
