# 决策：右欄卡片页与挂载线形态——现行定稿与被否变体存档

Status: implemented

## Problem

右欄卡片页经批1.13→1.21 六轮形态演进，被否变体的理由散在决策行内与版本历史里——
文档治理轮后这些"为什么不是那样"的记录需要一个防翻案载体。本笔记 = 该域
形态演进的 Alternatives 存档；现行裁决的权威仍在 `FEATURES.md` §9 与 `STYLE.md` §5.8。

## Decision（现行形态，用户逐轮定案）

- **两张卡并排在底板上**（批1.18 定稿）：阅读卡与卡片页同顶同底同卡面，中间一道沟露出底板。
- **纸钉死不动**：`--page-w` 锚定视口，阅读卡收窄的 re-center 由 `.reader-stage` 位移补偿
  （`--slot-w`×½）抵消——开合全程纸零挪动、kookit 零重排；批1.19 起开合只过渡
  `@property --slot-w` 一个值（单驱动）。
- **呼出制**（批1.15）：卡片页默认收起，召唤 = 右上角「卡」按钮（批1.21 鼠标主路径）/
  `` ` `` 总开关 / `p` / `c` / 命令面板「呼出X」。
- **挂载线本体退役**（批1.20）：目录 = 阅读卡左缘内嵌件（半高起排、压印字、显影按距离）；
  **折叠语法全站退役**（目录常驻、`t` 强隐藏）。
- **单槽位**；阅读态背景 = 底板本色 `--bg`（书库存活但不可见，scrim 压暗的视觉退役，阻挡职能保留）。

## Alternatives considered（被否变体，防翻案存档）

- **批1.16 常驻让位变体**（卡片页常驻、纸让位）：输在——纸宽被挤压违背"纸钉死"准绳；用户拍板
  "就是这个"时明确否掉。
- **批1.17 浮层变体**（卡片页浮于阅读卡上）：输在——形态未实机确认就被否（用户裁：形态改动
  必须实机自查后再回话——由此立下 ui-shot/截图自查的教训）。
- **默认展开**（2026-09-13 定，批1.15 作废）：输在——"卡片页需要是呼出"（用户定）；默认视野 =
  纯正文 + 目录，重开书保持收起。
- **顶栏标签条**（`ReaderTabStrip`，v0.2.5 暂住）：输在——标签一多被挤到窗控边上（用户否）；
  方向已裁 = 侧栏分界线，v0.2.7 落为 `TagRail` 窄格形态。
- **镜像口径**（左垂挂贴卡缘）：输在——右段换形卡片页后失效；批1.13 退役（`mirrorOk` →
  `cardOk`，样张机检同步改量卡片中心）。
- **scrim 压暗书库**（批1.7d 阅读态背景）：输在——"两卡之间显示的应该仍然是纯色"（用户定）；
  v0.2.5 视觉退役、阻挡职能保留。
- **卡片页召唤 m1 右键菜单 / m2 右缘悬停**（批1.21 候选）：销案——「卡」压印按钮双位点中选。
- **线右段召唤位**（批1.16 清除）：输在——"顺手给右边的挂载线清掉"（用户定）；鼠标路径批1.21
  由「卡」按钮补回。

## Consequences

换来的：翻案防线集中一篇。付出的：本笔记须随现行形态变更
同步更新（事实层）；"实机确认后才回话"的教训随交接记录退役归 git，不在本笔记。
